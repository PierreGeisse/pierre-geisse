PROCÉDURE GITHUB — REPARTIR PROPREMENT
1. Supprimer tous les fichiers et dossiers actuels du repository.
2. Conserver uniquement le repository GitHub lui-même.
3. Décompresser cette archive sur le Mac.
4. Sur GitHub : Add file > Upload files.
5. Glisser TOUT le contenu de cette archive à la racine.
6. Commit changes.
7. Ne pas modifier Settings > Pages : le déploiement actuel continuera de fonctionner.
