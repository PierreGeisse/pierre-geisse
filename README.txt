MISE EN LIGNE GRATUITE AVEC GITHUB PAGES

1. Crée un compte sur github.com.
2. Crée un nouveau repository public, par exemple : pierre-geisse.
3. Envoie tout le contenu de ce dossier à la racine du repository.
4. Dans le repository : Settings > Pages.
5. Dans "Build and deployment", choisis :
   Source : Deploy from a branch
   Branch : main / root
6. Enregistre.
7. GitHub te donnera une adresse du type :
   https://TONCOMPTE.github.io/pierre-geisse/

MODIFICATIONS
- Les textes sont directement dans index.html.
- Les couleurs, tailles, espaces et mise en page sont dans styles.css.
- Les images sont dans assets/.
- Il n'y a aucune dépendance payante ni framework externe.
